# Референсні матеріали

## `fbreader-appstore/`

Скриншоти зі сторінки FBReader в App Store (`id1067172178`), версія 1.2.6, отримані через
публічний iTunes Lookup API 2026-08-03. Джерело:
`https://itunes.apple.com/lookup?id=1067172178`

**Призначення:** аналіз функціональності та інформаційної архітектури для побудови
функціонального аналога. Читаємо як специфікацію поведінки, не як художній матеріал.

**Обмеження — обов'язкові:**

- ⛔ Ці файли **не потрапляють у бінарник застосунку** і не використовуються як асети.
- ⛔ Не комітити в публічний репозиторій. Тримати в `.gitignore` або в приватному remote.
- ⛔ Не копіювати з них іконки, логотип, шрифтові накреслення, кольорові палітри як точні
  значення. З них беремо **структуру і поведінку**, а не пікселі.
- ✅ Можна: перелік і порядок пунктів меню, склад панелей, набір налаштувань, логіка жестів,
  склад контекстного меню виділення.

Юридична межа зафіксована в `PLAN.md`, розділ «Юридичні обмеження».
